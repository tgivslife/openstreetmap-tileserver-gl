# Installation

### Docker

Build from project root directory with:

    docker build . -t tileserver-gl

The docker container can be run like this:

    docker run --rm -it -v $(pwd):/data -p 8080:8080 tileserver-gl

Additional options (see [USAGE.md](2.USAGE.md)) can be passed to the TileServer GL by appending them to the end of this command.

* ``docker run ... tileserver-gl --file my-tiles.mbtiles`` -- explicitly specify which mbtiles to use (if you have more in the folder)
* ``docker run ... tileserver-gl --verbose`` -- to see the default config created automatically
* ``docker run ... tileserver-gl --config path-to-file/config.json`` -- explicitly specify a configuration file [config.json] (default: "config.json")
